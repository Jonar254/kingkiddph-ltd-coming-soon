# Kingkiddph Ltd — Coming Soon

Landing experience for Kingkiddph Ltd, a Kenya-based film and content production company.

## Tech Stack

- [Next.js 16](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [Tailwind CSS 3](https://tailwindcss.com/)

## Getting Started

Install dependencies and run the local dev server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Environment Variables

Create `.env.local` and set the following:

```bash
NEXT_PUBLIC_WEB3FORMS_ACCESS_KEY=your_key_here
```

## Building for Production

```bash
pnpm build
pnpm start
```

## Deploying

When you're ready, push to the new repository:

```bash
git remote add origin https://github.com/Jonar254/kingkiddph-ltd-coming-soon.git
git branch -M main
git push -u origin main
```
